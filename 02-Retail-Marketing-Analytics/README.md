# 📊 Retail & Marketing Analytics

## 📌 Overview

This project analyzes retail sales data to understand **sales performance, customer segments, product performance, regional trends, profitability, and shipping patterns**.

The project follows a simple end-to-end data analytics workflow using **SQL, Python, Excel, and Power BI**.

---

## 🎯 Objectives

- Analyze sales and profit trends
- Identify top-performing products and categories
- Understand customer segments
- Compare regional performance
- Analyze discounts and profitability
- Explore shipping patterns
- Create business-focused visualizations

---

## 🛠️ Tools Used

**Excel** • **SQL Server** • **Python** • **Pandas** • **Power BI**

---

## 📊 Key Analysis

- Sales & Profit Analysis
- Customer Segment Analysis
- Product & Category Performance
- Regional Analysis
- Discount & Profitability Analysis
- Shipping Analysis
- Monthly Sales Trends
