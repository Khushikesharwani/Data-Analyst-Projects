# 🏥 Healthcare Analytics

## 📌 Overview

This project focuses on analyzing healthcare data to understand **patient admissions, department performance, financial trends, and overall hospital operations**.

The project follows a data analytics workflow using **Python, SQL, Excel, and data visualization** techniques.

---

## 🎯 Objectives

- Analyze patient admission trends
- Understand department performance
- Explore patient demographics
- Analyze financial and billing patterns
- Identify important healthcare trends
- Present findings through data visualizations

---

## 🛠️ Tools Used

**Python** • **Pandas** • **Matplotlib** • **SQL** • **Excel**

## 📊 Key Analysis

- Data Visualization
